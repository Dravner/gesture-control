# Самостоятельное приложение

Откройте `dist/Жестовое управление.app`. Сборка для Apple Silicon arm64 и macOS 15+, не универсальная для Intel. В комплекте Python, Qt, PyObjC, модели и альтернативные исследовательские зависимости; системный Python не нужен. Камера и системный ввод при запуске выключены. Apple Vision выбран на первом запуске, сохранённый выбор трекера сохраняется.

1. Нажмите «Запустить» и разрешите камеру, если macOS запросит её. Если первый запуск завершился до разрешения, повторите «Продолжить».
2. Используйте основной профиль и «Курсор движением кисти · 2D». Двигайте кисть с поднятым указательным пальцем; это относительная мышь, не физический луч.
3. В «Настройки…» можно изменить чувствительность/сглаживание, прокрутку, подтверждение поз, длину свайпа, щипок, задержку переноса и действия жестов. Сначала проверьте результат в тестовом окне.
4. Для ввода в других приложениях разрешите «Жестовое управление» в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ», затем включите системный ввод в приложении.

Пять жестов: указательный палец — курсор; щипок — клик (удержание — перенос); V — вертикальная прокрутка; три поднятых пальца и движение влево/вправо — две команды навигации. Между повторными свайпами расслабьте пальцы. При щипке и прокрутке курсор фиксируется.

Пользовательские жесты: «Настройки… → Действия → Открыть мастер своих жестов». Мастер переключает расширенный профиль; записывайте обучающие примеры отдельно от TRIAL. Произвольные новые жесты требуют проверки, их качество не следует из работы пяти основных.

Данные приложения: `~/Library/Application Support/GestureControl/data` (профили, параметры, числовые измерения сеансов); ресурсы пакета не редактируются. Профили разработки автоматически не импортируются, поэтому ранее записанные примеры остаются в `data/gesture_profiles` исходного проекта. Не удаляйте эти каталоги для обновления. Изображения камеры в обычных сеансах не сохраняются.

Восстановление принятых параметров: «Сбросить параметры» в настройках сбрасывает только числовые настройки, назначения жестов остаются. Изменение параметров отключает ввод; остановка/потеря руки освобождает нажатую кнопку.

Сборка: `.venv/bin/python tools/build_app.py`; диагностика без камеры: `dist/Жестовое управление.app/Contents/MacOS/GestureControl --diagnostics`. Источник сборки — собственный код проекта и зависимости из официальных пакетных репозиториев. Подпись локальная ad-hoc, не Apple notarization; перенос на другой компьютер может потребовать отдельной сборки/подписания.
