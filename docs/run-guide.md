# Запуск и управление

Двойной клик по «Запустить систему.command» либо из Terminal:

```sh
cd /Users/a1111/schcool/diplom/gesture-control
.venv/bin/python launch.py
```

Первый запуск: разрешите камеру приложению запуска (Terminal/Python/Codex). Для реальной мыши и клавиатуры также нужен «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ». Разрешение проверяется, не обходится. По умолчанию системный ввод отключён.

Нажмите «Запустить», проверьте изображение кисти. Основной профиль — «Наведение на экран · пять жестов». «Пауза», «Стоп», смена источника и закрытие окна освобождают удерживаемую кнопку. Потеря кисти завершает перетаскивание.

В «Трекинг кисти» доступны MediaPipe и Apple Vision2D (macOS). Смена останавливает камеру и ввод; затем снова нажмите «Запустить». Apple Vision не выдаёт3D-координат кисти, поэтому выбирает2D и блокирует3D-луч. В рабочем2D-профиле надёжность оценивается по опорным суставам и пальцам, нужным конкретной команде; скрытый согнутый кончик не отбрасывает всю кисть. Полные личные шаблоны требуют уверенной полной кисти. Если рука теряется, сравните с MediaPipe на той же удобной позе. Настройки рабочего пространства зависят от backend; старый файл не меняется без сохранения. После смены модели отдельно проверяйте личные жесты через TRIAL.

Для рабочего 2D-управления:

1. Выберите «Курсор движением кисти · 2D». Откройте «Рабочая область · 2D», включите относительное перемещение и сохраните. Уменьшение ширины/высоты увеличивает чувствительность. Ранее сохранённая абсолютная настройка сохраняет свой режим, пока вы явно его не измените.
2. Держите кисть целиком в кадре, ладонью к камере, указательный палец вверх, остальные три согнуты. После спокойной паузы движение кисти двигает курсор. Для возврата руки в удобное положение расслабьте позу или уберите руку, переместите кисть и снова вытяните указательный палец. Курсор остаётся на месте при повторном захвате. При включённом OS input захват начинается с текущего системного курсора, включая положение после трекпада.
3. Откройте «Проверка пяти жестов». Можно открыть окно без видимой руки, но включить ввод — только при свежем отслеживании. В тестовом окне есть отдельный флажок включения и Escape для остановки. Реально полученные клики, прокрутка и переходы фиксируются отдельно от распознанных команд.
4. Сначала проверьте наведение и возврат руки; затем короткие щипки, V-прокрутку и оба свайпа. «Стоп» сохраняет числовой сеанс; изображения камеры не записываются.

Пять классов основного профиля:

- Указательный палец: курсор движением кисти в 2D-режиме.
- Щипок большого и указательного при согнутых остальных трёх: короткое соединение и отпускание — левый клик; удержание более 0,45 с — перетаскивание. Перед щипком курсор фиксируется; перенос следует движению кисти.
- Два вытянутых пальца V: движение вверх/вниз прокручивает содержимое; курсор остаётся на месте.
- Три пальца (указательный, средний, безымянный; мизинец согнут), движение влево: один переход назад; курсор зафиксирован.
- Три пальца, движение вправо: один переход вперёд. Между переходами расслабьте пальцы примерно на0,3с. Два пальца используются только для прокрутки; неподвижная пауза ладонью не нужна.

Если пальцы перекрывают друг друга или кисть направлена ребром/тылом к камере, распознавание может пропадать. 2D-режим рассчитан на удобную видимую позу; он не измеряет физическую точку, куда направлена ось пальца.

Экспериментальный 3D-режим сохраняет прежнюю калибровку по девяти целям и независимую проверку по пяти. После выбора «Экспериментальный луч пальца · 3D» на каждой цели нажмите Space: 1,2 с подготовки, 2,2 с сбора. При отказе fit можно переснять отдельную цель. Повторные пользовательские сборы пока не дали надёжной геометрии; этот режим не считается рабочим физическим лазером. Изменение камеры, формата, дисплея или FOV требует нового сбора. FOV60° — приближение.

Для правого клика, Space, других горячих клавиш и персональных жестов выберите расширенный профиль. Его распознаватели не конкурируют с пятью классами основного профиля.

Настройка команды: выберите жест в библиотеке, действие и клавиши (например command,shift,s), сохраните. Для нового жеста введите имя, выберите статический/динамический тип и действие. Для существующего своего жеста достаточно выбрать его в библиотеке: имя и тип заполняются автоматически.

Обучение v2: нажмите «Обучить по отдельным примерам · TRAIN». По умолчанию мастер собирает три отдельных примера. Перед каждым — 3 с подготовки, затем 2 с статической позы или 3 с полного движения. Для динамического жеста начинайте движение после отсчёта, выполните его целиком, затем остановитесь или уберите руку. Мастер сообщает покрытие руки, доступность пространственных точек и причину отклонения плохой записи. Ввод в ОС отключён. Старые примеры сохраняются; новые пространственные примеры имеют приоритет. Допуск калибруется по обучающим примерам. Ручная настройка допуска сохраняет явное значение и отключает автокалибровку этого профиля.

Проверка: выберите свой жест и нажмите «Проверить выбранный жест · TRIAL». Три новые попытки проходят отдельно от обучения; их координаты и результаты сохраняются в сеансе, но не меняют шаблоны и допуск. Во время проверки используется режим личных жестов, нейросетевые команды и ввод в ОС выключены. Выполняйте жест только после отсчёта, затем остановитесь/уберите руку; мастер учитывает короткий интервал завершения движения. Не считайте совпадение записанного шаблона проверкой качества. После успешного TRIAL проверьте также обычный поток, фоновые движения и нужные задачи.

Кнопка одиночной записи сохранена для дополнительных примеров. «Завершить сейчас» обрезает запись, «Отменить» прерывает протокол; уже сохранённые примеры остаются. Минимум 5 видимых кадров для static и 8 для dynamic, покрытие руки ≥60%, для движения проверяется достаточная вариативность. Шаблоны хранятся локально в data/gesture_profiles/gestures.json.

Для буквенных горячих клавиш macOS использует физические коды стандартной раскладки; проверяйте комбинацию в целевом приложении. Разрешены клавиши/мышь, произвольное выполнение shell не предусмотрено.

Видеофайл всегда работает только как проверка с журналом, без реальных команд ОС:

```sh
.venv/bin/python launch.py --video research/data/videos/ИМЯ.avi
```

Режимы команд: «Совместное управление» сочетает встроенные и свои жесты; «Личные жесты» пропускает только свои; «Только указатель» отключает персональные дискретные команды. Персональная ветвь использует 25 признаков формы кисти и пространственные координаты MediaPipe, если доступны. Динамическая ветвь сравнивает полные причинно выделенные эпизоды с примерами посредством DTW, учитывает направление, движение и неполное завершение. Краткая потеря кисти сохраняет эпизод; перетаскивание освобождается сразу. Приоритет незавершённого персонального движения подавляет конфликтующие статические/непрерывные команды. Полноценный поиск подпоследовательности SPRING пока не реализован.

«Допуск своего жеста» — расстояние в персональном представлении, а не вероятность. Больше — свободнее, меньше — строже. Общий нейросетевой порог 0,75 к нему не применяется. Флажок «Учитывать поворот кисти» для статических профилей нужен, если похожие формы с разным направлением должны иметь разные команды. Не создавайте несколько профилей с одинаковой формой и разными именами: близкие кандидаты могут быть отклонены как неоднозначные.

Пользовательские «сall» (первая буква кириллическая) и «switch» сохранены с действием «Без команды». Для управления назначьте действие после независимой проверки. Старые 2D-примеры не содержат глубины; для вращений рекомендуется новый TRAIN с пространственными точками. По состоянию до нового TRIAL качество v2 на ваших жестах ещё не подтверждено.

Обученные checkpoint models/streaming_window.pth, streaming_two_stage.pth, streaming_joint.pth сохранены для исследования. Joint выбран по validation публичного эксперимента v1, но свободные нейросетевые команды показали недостаточную надёжность. Поэтому по умолчанию флажок «Экспериментальная нейросеть управляет командами» выключен. При его включении выбранный метод требует уверенности ≥0,75, активности ≥0,7 и трёх отсчётов при 10 Гц; повтор — после 0,3 с нейтрального состояния и интервала 0,5 с. Публичные результаты не доказывают универсальность управления.

Камера и распознавание работают в отдельных потоках с одним последним кадром/результатом; очередь не растёт при медленной обработке. GUI показывает FPS, возраст кадра, длительность обработки и диагностическую фазу личного жеста. Возраст кадра не равен полной задержке от движения до реакции ОС.

Сеансы камеры сохраняют числовые признаки, распознанные состояния и события в data/sessions при остановке/паузе. Изображения не записываются. Метод, порог и время удержания сохраняются в data/ui_settings.json. Для научной оценки сеансы необходимо независимо разметить; запись шаблона не считается тестом точности.

Новая установка (Python 3.11–3.14, подходящие wheels зависят от версии):
```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

В поставленном проекте окружение уже подготовлено. Старые realtime_inference.py и модели сохранены для воспроизводимости.


### Исправление остановок окна · 08.10.2026

Устранена воспроизведённая утечка RGBA-буферов в Apple Vision: кадры передаются через копию в нативном NSData. Тест пяти жестов открывается обычным дочерним окном macOS, без автоматического fullscreen. При отсутствии свежего кадра дольше0,5с управление освобождается и выключается; старое изображение заменяется сообщением. Ошибка камеры также видна внутри теста. После восстановления кадров ввод самостоятельно не включается: сначала проверьте живую подсказку и затем включите его вручную. Если поток остановлен, закройте тест, нажмите «Продолжить» и снова откройте «Проверка пяти жестов».

Диагностика и графики памяти сохранены отдельно в reports/runtime-freeze-20261008. Полная проверка собственных тестов: `QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q tests` (264passed). Каталог research/references содержит сторонние тесты для изучения и не входит в эту команду.

В v4.3 короткая потеря кисти до0,20с сохраняет режим, но приостанавливает команды. Прокрутка отправляется непрерывными пикселями с фильтрацией по времени. Сеанс сохраняет handedness и confidence всех21 суставов; сторона модели может ошибаться и не заменяет вашу разметку. Результаты и ограничения — reports/bilateral-stability-20261008/README.md.

Тестscroll в новой сцене: наведите курсор на большую цветную область, поднимите два пальца и двигайте кисть вверх/вниз. Число «Прокрутка: …px» показывает реальное смещение виджета. Дляswipe используйте три пальца; цветная карточка внизу меняет страницу.
