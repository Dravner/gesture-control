# Проверка поставки

Проект: RGB-камера → MediaPipe → статическая/временная/персональная ветви → контроллер → журнал или macOS-ввод. Совместная временная модель выбрана по validation; её результаты не подтверждают универсальную высокую точность свободных команд.

- Полный набор автоматических проверок: `.venv/bin/python -m pytest -q` — 114 passed, 3,85 с, 7 октября 2026. Проверены причинность моделей, разделение людей, метрики событий, безопасность видео/записи, сохранение профилей/сеансов/настроек, назначение команд, освобождение кнопки при потере руки, двойной клик и отсутствие повторов при кратком провале классификации.
- Нативное окно реально открыто на MacBook M2 Pro; камера разрешена и видеопоток наблюдался. Системный ввод при старте выключен. Камера не используется автоматическими unit-тестами.
- Конвейер v1 проверен на 1200 последовательных кадрах публичного тестового видео: 1072 кадра с кистью, CPU p50 11,975 мс / p95 24,106 мс. Источник, измерения и события: `reports/runtime-validation`. Не включены live capture, отрисовка, дисплей и задержка реального ввода в ОС. Персональные шаблоны в этом измерении отсутствуют.
- Реальные публичные эксперименты: 40 видео, 10 человек, train/val/test 6/2/2 человека; 162937 исходных кадров. Есть три обученных checkpoint, конфигурации, исходные предсказания, кривые, матрицы ошибок и измерения CPU/MPS. Детали: `research/README.md`.
- Дополнительное сравнение персонального DTW использует 104 отдельно размеченных сегмента публичных видео. Это изолированное распознавание при известных границах, а не тест полного потока.
- Пользовательские «сall» и «switch» сохранены локально. Первый независимый сеанс выявил ошибки порогов и сброса истории. После исправлений повторный прогон этого диагностического сеанса обнаружил по три события каждого жеста; он не является независимой проверкой исправленной версии. Данные: `reports/personal-debug-replay.json`.
- Quartz-ввод покрыт проверками последовательностей событий с подставным backend; доступ Accessibility проверяется системным API. Автоматические тесты не отправляют мышь или клавиши в сторонние приложения. Реальное качество взаимодействия с ОС и эргономика требуют пользовательской проверки задач.

Запуск: `Запустить систему.command`; руководство: `docs/run-guide.md`. Версии локального окружения: `reports/environment-freeze.txt`. На другом компьютере зависимости устанавливаются по requirements.txt; переносимость и нижний предел оборудования экспериментом не установлены.
