# Приложение и оптимизация 9 октября 2026

Базовая принятая пользователем версия:6021c2c (origin/dev). Новый код сохраняет геометрию/масштаб камеры и принятые пороги щипка/чувствительность; добавляет настройки, явную ленивую загрузку исследовательского Torch и coalesced queued Qt уведомления.

## Что измерено

`handoff_benchmark.py`: два синтетических режима Qt, по180 доставленных результатов. Источник период17мс, polling30мс сравнивается с queued Signal. Измеряется result→consumer, не камера→OS и не точность жестов. Poll: median10.333мс,p95 22.432мс; queued:median0.152мс,p95 .234мс. В реальном конвейере ожидающее уведомление одно, кадры/результаты заменяются последними, действия выполняются только в GUI.100мс timer остаётся watchdog; видео остаётся30мс.

`startup_gui_benchmark.py`: по3 свежих процесса, создание исходного Qtокна без камеры; файловыйcache не очищался. Baseline имитирует прежний eager importTorch и Engine(default); optimized Engine(load_models=False). Median0.866→0.335сек;peakRSS265.3→102.8MiB. Это исходный offscreen GUI, не запуск упакованного.app. В стабильномGUI Torch отсутствует в sys.modules, для исследовательского режима загружается явно; ошибка checkpoint выключает этот режим и сообщает причину.

Подтверждение указательной позы для относительного наведения100мс вместо220мс; рука может двигаться при захвате, первый курсор закрепляется на текущей позиции. Абсолютный экспериментальный луч сохраняет прежние ограничения. Прокрутка изpointer получает владение после60мс подтверждения V без дополнительного160мс ожидания; singleframeV не переключает режим. Щипок, потери руки, подтверждение трехпальцевой навигации и отпускание кнопки сохранены.

## Настройки и проверки

Отдельный nativeдиалог хранит чувствительность .3–3×, сглаживание0–100, scroll .5–5×, poseconfirm30–160мс, pointeracquire60–300мс, длину свайпа4–20%ширины, pinch .16–.32, перенос250–1000мс и действия пяти жестов. Порог отпускания щипка всегда выше закрытия на.10. Ошибочные клавиши отклоняются целиком; файл профиля заменяется атомарно. Изменение только чувствительности сохраняет прежние нестандартные назначения. Системный ввод после настройки выключен.

Полный pytest перед финальным compatibilityregression:306passed16.38сек. Финальный счёт фиксируется отдельно вverification.txt. Автотесты проверяют алгоритмы и безопасность переключений, не гарантируют100% распознавания у пользователя. Базовая качественная оценка — один пользователь, без формального исследования эргономики.
