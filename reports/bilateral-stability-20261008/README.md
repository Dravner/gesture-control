# Две руки и устойчивость управления · 08.10.2026

Пользовательский результат предыдущей сборки: справа почти ничего не работает, слева point частично работает; щипок приемлем, прокрутка дёргается, palm-arm свайпы неудобны. Этот отзыв — основание изменений, не заменён результатами на датасете. Статья не редактировалась.

## Что установлено

Сеанс20261008T183159-a8604adb содержит19843 наблюдения,12273 принятых кисти,7570 отсутствий. Исходные классы:4368 uncertain,2589point,1031victory. Chirality/per-joint confidence тогда не сохранялись, поэтому нельзя точно приписать провалы правой руке или восстановить координаты отвергнутых кистей. Зеркальное преобразование12273 сохранённых наборов координат не меняет старые классы: явного одностороннего правила в классификаторе нет.

Отбрасывание всей кисти по минимальной confidence всех21 суставов, отсутствие состояния пальцев, моментальный сброс режима при no_hand, line-scroll без фильтрации и palm-arm на широкую амплитуду — подтверждённые механизмы старого кода, согласующиеся с отзывом. Не утверждается, что каждый пользовательский провал вызван только ими.

## Изменения рабочего2D-профиля

- Apple Vision допускает частичную кисть: критичны запястье/костяшки/указательный, а не уверенность каждого скрытого согнутого кончика. Обычный порог опорных суставов0,25. Неизвестные координаты сохраняются как неизвестные вместе с качеством. Их нули в совместимом векторе не используются для наведения/поз; полный шаблонный профиль такие наблюдения отвергает.
- Опора движения — фиксированная середина запястья и средней костяшки. Не меняющийся состав «среднего из видимых суставов»; кончик указательного управляет позой, кисть — перемещением. Это2D-устройство, не физический лазер.
- ImagePoseLatch использует собственное состояние каждого пальца, отдельные критерии начала/удержания, reach+extent+radial evidence для защиты от коротких «прямых» проекций согнутого пальца. Правила одинаковы для обеих рук и не зависят от chirality. Пропавшее наблюдение пальца можно удержать не дольше0,18с. Для скрытых согнутых кончиков нижняя confidence допустима только с видимой костяшкой/PIP и независимо коротким extent; она не открывает палец.
- Короткий no_hand≤0,20с сохраняет pointer/scroll, приостанавливает команды и не экстраполирует курсор. Возврат переустанавливает опору без скачка. Уверенная альтернатива pointer подтверждается0,06с. Длительная потеря сбрасывает режим; drag при потере освобождается сразу. Raw tracking и режим управления сохраняются раздельно.
- Прокрутка: EMA с постоянной времени55мс, подвижная зона покоя, дробные непрерывные Quartz pixel-scroll события и предел1800px/s. Курсор фиксирован. Рывок координат/разрыв траектории меняет опору, не «догоняет» её. Line-scroll сохранён для старых расширенных профилей.
- Два пальца: вертикальная траектория прокручивает, горизонтальная даёт один переход после8% ширины кадра. Ось выбирается после небольшого движения с отношением1,6; после перехода нужно расслабить пальцы. Отдельное «вооружение» открытой ладонью в2D убрано. Предпочтение по этому предложению запрошено, пока выбран рекомендованный вариант. Старый экспериментальный3D-контроллер сохраняет palm-swipe.
- Ненадёжная дистанция thumb/index при уже подтверждённом щипке не считается его отпусканием: клик не выдаётся, состояние кратко ждёт и затем отменяется. Эта последняя поправка была внесена после начала пользовательского теста и требует перезапуска запущенного окна.

Пороги — начальная инженерная настройка, не объявляются оптимумом или результатом клинической проверки эргономики.

Последний pinch-guard находится в файлах, но ещё не в этом запущенном процессе: перезапуск после завершения пользовательского теста.
