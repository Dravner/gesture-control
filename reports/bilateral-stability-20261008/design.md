# Исправление существующего потока управления

Цель пользователя: одинаковые жесты каждой рукой по отдельности, устойчивое наведение, плавная прокрутка, удобные два направления навигации. Камера RGB, встроенный экран MacBook; внешние датчики не добавляются. Статья заморожена. Одновременные независимые курсоры двумя руками не требуются.

Существующая архитектура camera → tracker → immutable feature → GUI controller → Quartz сохраняется. Проверяемые изменения:
1. Apple Vision сохраняет per-joint confidence/handedness; пригодность ладони оценивается по опорным суставам и указательному пальцу, а не минимуму всех21. Ненадёжные суставы остаются ненадёжными, не подменяются уверенными наблюдениями.
2. В рабочем2D-профиле отдельное временное состояние пальцев: две границы разгибания/сгибания, независимая проверка расстояния кончика от костяшки/запястья. Короткое исчезновение сомкнутых пальцев не выключает указатель. Уверенная смена позы переключает режим с коротким подтверждением. Chirality не меняет правила жестов.
3. Короткий no_hand сохраняет режим, но не генерирует команды и не экстраполирует координаты. При возвращении relative pointer пересаживает опору без скачка; при длительной потере — сброс. Перетаскивание при потере освобождается сразу.
4. Прокрутка: EMA по времени, дробные пиксели, ограничение скорости, фиксация курсора. При разрыве траектории новая опора без компенсационного рывка. Старый line-scroll остаётся совместимым для расширенных профилей.
5. Свайпы: ожидается ответ на предложенное управление двумя пальцами с выбором оси в начале; отдельное старое palm-arm может остаться совместимым. Нельзя просто ослабить все пороги и выдавать случайные команды.

Проверка: зеркальные последовательности обеих рук, колебание суставов, потеря1–4кадров/длительная потеря/скачок/смена руки, остановка послеdrag, отсутствиеmove во времяscroll, равная суммарная прокрутка15/30/60FPS, единственный свайп после возврата в нейтраль. Сохранённый сеанс не имеет разметки намерений и не служит основанием для accuracy. После автоматических проверок нужна короткая независимая пользовательская проверка.

Источники повторно прочитаны: OorjitSethi gesture-mouse-macos (MIT), Pawvis (MIT), vivek-ganti gesture-mouse (в локальной версии нет лицензии: идеи, без буквального копирования), HandWavey (Leap Motion, не RGB), RuslanKoroy (GPL3). Публичная доступность не означает отсутствие условий лицензии. Пока перенос самостоятельный, прямой порт потребует сохранения notices.
